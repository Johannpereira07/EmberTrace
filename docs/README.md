## Precedence

1. **PRD (`01`)** is the source of truth for *what* we build: requirements, priorities, behavior.
2. **Data Profile (`07`)** and **Calibration Report (`11`)** are the source of truth for *facts about the data and calibration* (dates, codes, columns, conversion factors, hold-out and splice metrics).
3. **Implementation Plan (`03`)** settles what the PRD leaves open (its Appendix A decisions) and owns schedule, ownership and tasks. It must not contradict the PRD.
4. **API Spec (`04`)** is the contract between backend and frontend, inside the PRD's requirements.
5. **Architecture (`02`)** covers background science and methodology only where nothing above overrides it.

If two docs disagree in a way these rules don't settle, stop and ask the team (see [`AGENTS.md`](../AGENTS.md)).
